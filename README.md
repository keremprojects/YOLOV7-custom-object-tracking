## 🎥 Example Output Video

⚠️ Due to the complex environment setup (YOLOv7 dependencies, model weights, server time sync, etc.), running this project may take significant time to reproduce.

To provide a clear overview of the system's capabilities without full environment setup, a sample result video is included in the repository:  
📁 `demo_output.mp4`

The video demonstrates:
- Real-time object detection with bounding boxes.
- QR code recognition and decoding.
- Target locking logic with visual indicators.
- Timed kill confirmation and JSON logging.
